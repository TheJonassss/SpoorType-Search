SPOOR

A free search tool for the type community. Type the name of a Google Fonts family and get back a list of real websites that load that font in their code, ranked by popularity — each linking straight to the site.

SPOOR reads the public HTTP Archive dataset. It surfaces real usage, not mentions — a large sample, not a census.
